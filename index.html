4. Physics behind the simulator

Target thickness: d₀ = N × GPC
Actual thickness: d = d₀ + Δd
Tunneling: T ≈ exp(−2κd)
Capacitance: C = kε₀A / d
Relative tunneling: R = exp(−2κΔd)
Deposition time: t = N × 5 s
Equivalent oxide thickness: EOT = d × 3.9 / k

Assumptions: HfO₂ relative permittivity k = 20; κ = 3 nm⁻¹; capacitor area A = 1 µm²; vacuum permittivity ε₀ = 8.8541878128 × 10⁻¹² F/m; constant growth per cycle and 5 seconds per cycle. Capacitance calculations convert nm to meters.

Model limitations: This is an educational, equation-based parametric model, not an experimentally calibrated device simulation. It assumes a continuous, uniform film and a simplified tunneling barrier. T is a dimensionless transmission factor, not a measured gate leakage current. The model does not establish manufacturability or replicate IBM's proprietary transistor process. Technology-node names are not physical dielectric thicknesses.
